# SARA Performance — Landing Page

Landing page institucional da SARA Performance, isolada do backend NestJS deste repositório.

## Executar localmente

```bash
cd landing-page
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:3000`.

## Escopo

Esta pasta contém somente a aplicação front-end institucional. Nenhum arquivo do backend, banco de dados, autenticação ou regras de negócio é alterado por esta entrega.

Os espaços reservados para futuros prints do produto estão documentados em `public/sara/README.md`.
